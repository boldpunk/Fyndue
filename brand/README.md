# Fyndue brand sources

Vector logo sources (wordmark outlined from Geist SemiBold). The full kit — app icons for iOS/Android, favicons, link previews, brandbook and case presentation — is distributed as `Fyndue-Brand-Kit.zip`.

The mark is drawn on a 512 grid: stroke 72, corner radius 36, tile radius 120, mint dot r = 36 at (332, 356). Colors: see `colors.txt`.

Web assets in use: `app/favicon.ico`, `app/icon.svg`, `app/apple-icon.png`, `app/opengraph-image.png`, `app/twitter-image.png`, `public/icon-*.png`; the in-app mark is `components/layout/logo.tsx`.
